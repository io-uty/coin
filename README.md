# 코인 자동매매 프로그램

RSI·MACD 기술 지표를 조합한 자동매매 로직을 직접 설계하고,
과거 데이터로 백테스트를 진행한 프로젝트입니다.

## 주요 기능

- RSI·MACD 지표 기반 매수/매도 조건 설계
- 과거 데이터 백테스트 및 전략별 수익률 비교
- 1분봉 기반 실시간 가격·지표 시각화
- 실계좌 연동 실시간 거래 테스트

## 기술 스택

- Python
- Matplotlib (시각화)
- 업비트 API

## 파일 구조

| 파일 | 설명 |
|------|------|
| login.py | API 키 인증 및 연결 |
| order.py | 기본 매수/매도 주문 |
| order2.py | 개선된 주문 로직 |
| 01.py ~ 05.py | 전략별 백테스트 |

## 결과

전략별 수익률 비교 및 매매 조건이 수익률에 미치는 영향 분석 완료
실계좌 연동 실시간 거래 테스트 완료
